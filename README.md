
# 📱 UI/UX Design Portfolio – Figma Projects

## 🎨 Overview
This repository contains UI/UX designs created using Figma for multiple mobile and web applications.  
The designs focus on user-centered experiences, visual clarity, and consistency, suitable for cross-platform application development.

---

## 🎯 Objective
The purpose of this portfolio is to demonstrate:
- Practical UI/UX design skills using Figma
- Ability to design interfaces for Web, Android, and iOS platforms
- Creation of design systems using mood boards and style guides
- Developer-ready UI designs aligned with modern frontend frameworks

---

## 🛠 Tools & Design Approach
- Design Tool: Figma  
- Design Principles:
  - User-centered design
  - Visual hierarchy and spacing
  - Consistent color and typography
  - Responsive and intuitive layouts
